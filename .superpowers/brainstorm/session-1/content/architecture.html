Modular Architecture Strategy

How we'll implement this without touching stable core logic.

Current Flow (Stable)
AssemblyAI WS
↓ transcript text
BaseProvider / Engine
↓ broadcast
HUD (Raw Text)
Proposed Modular Flow
AssemblyAI WS (v3)
↓ text + word-level labels
SpeakerManager (New)
↓ formatted text with [SX]
HUD (No HUD changes needed!)

Technical Advantages

  • Isolation: The SpeakerManager lives in its own file. If it fails, the rest of the app doesn't know.
  • Configurable: If enable_diarization = false, we don't even add the parameter to the URL, and the SpeakerManager is never instantiated.
  • No HUD Bloat: By formatting the string before it hits the HUD, we don't have to change any complex UI rendering code.
